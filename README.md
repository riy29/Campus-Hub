# Campus Hub 🏫

A frontend-only platform for campus services like:
- Laundry booking
- Mess food preference
- Lost & Found
- Notices & Issue reporting

## 🚀 Tech Stack
- HTML5, Tailwind CSS
- Font Awesome Icons
- Vanilla JavaScript
- No backend (uses localStorage)

## 📦 Features
- User registration/login (localStorage)
- Modal-based UI for each service
- Mobile-friendly and responsive
- Feedback & report submission
